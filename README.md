# Приложение "Карта с маркерами" (React Native + Expo)

## Описание
Мобильное приложение, позволяющее пользователям ставить маркеры на карте долгим нажатием, просматривать их детали и управлять привязанными к ним изображениями (добавлять из галереи или камеры и удалять).

## Инструкции по установке и запуску
1. Убедитесь, что у вас установлен **Node.js** (LTS версия) и **Expo CLI**.
2. Клонируйте репозиторий или скачайте исходный код.
3. Установите зависимости:
   ```bash
   npm install
4. Для того чтобы запустить программу в терминале введите "npx expo start"
